# Portal personal – Frontend con HTML

**Curso:** Diseño de sistemas en Internet – Semana 11
**Autor:** Alejandro Santamaría

## Descripción
Página personal creada con HTML básico (`index.html`) que aplica la estructura fundamental del frontend.

## Estructura
```
portal/
├── index.html
├── img/
│   └── IMAGE.JFIF
└── README.md
```

## Elementos utilizados
- `<html>`, `<head>`, `<body>`
- Encabezado principal `<h1>` con el nombre y subtítulos `<h2>`
- Párrafo `<p>` de presentación personal
- Listas `<ul>` / `<li>` de intereses y habilidades
- Imagen `<img>` y enlaces `<a>` a redes y sitios favoritos

## Cómo ejecutarlo
Abrir `index.html` en cualquier navegador.
